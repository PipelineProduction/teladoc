# Quick Task Plan 261126-nz1: Rebuild Mailing Lists Action Under Configuration Menu

## Goal
Add a **Rebuild Mailing Lists** wizard/action under **vHealth Process > Configuration > Rebuild Mailing Lists** that evaluates all `mailing.contact` records against SharpSpring-style list rules (with a default `vHealth Contact == True` checkbox rule) and synchronizes membership across all 6 core lists:
1. `All Live Contacts [SEND TO ALL]` (`x_studio_vhealth_contact == True`)
2. `All REGISTERED members` (`x_studio_vhealth_contact == True` AND `((x_studio_app_unique_registered == 'Yes' AND x_studio_location_us_or_canada == True) OR (x_studio_app_registered == 'Yes' AND x_studio_location_us_or_canada == True))`)
3. `All Contacts - TH` (`x_studio_vhealth_contact == True` AND `x_studio_cohort_group == 'TH'`)
4. `All Contacts - TH + MH` (`x_studio_vhealth_contact == True` AND `x_studio_cohort_group == 'TH + MH'`)
5. `All Contacts - PC` (`x_studio_vhealth_contact == True` AND `x_studio_cohort_group == 'PC'`)
6. `All Contacts - MH` (`x_studio_vhealth_contact == True` AND `x_studio_cohort_group == 'MH'`)

## Tasks
1. Update `_get_or_create_list` in `models/imports.py` (and reuse in `models/action_group_schedule.py`) to match existing `mailing.list` records case-insensitively (`=ilike` + trim) before creating a new list.
2. Create `wizard/rebuild_mailing_lists_wizard.py` (`vhealth.rebuild.mailing.lists.wizard`) with:
   - `require_vhealth_contact` checkbox (default `True`).
   - Editable `Many2one("mailing.list")` selectors pre-matched by name (auto-created on rebuild if missing).
   - Live rule preview counts and differential sync (`[(4, id)]` / `[(3, id)]`) that preserves `opt_out` flags and unrelated list memberships.
3. Add `views/rebuild_mailing_lists_wizard_views.xml`, menu item in `views/menus.xml`, ACLs in `security/ir.access.csv`, register in `wizard/__init__.py` and `__manifest__.py` (`20.0.1.0.22`), and add tests in `tests/test_smoke.py`.
