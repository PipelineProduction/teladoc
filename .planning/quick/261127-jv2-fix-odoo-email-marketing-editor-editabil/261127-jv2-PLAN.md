# Quick Task Plan 261127-jv2: Restore Odoo Email Marketing Visual Editor Editability Across All vHealth Templates

## Root Cause
In `261126-kmn` and `261126-mg3`, writing pure `<table>` Gmail HTML into `mailing.mailing.body_arch` removed Odoo's Mass Mailing editor wrapper (`.o_layout`, `<style id="design-element">`, `.o_mail_wrapper`, `.o_mail_wrapper_td.oe_structure`, and `<section class="o_mail_snippet_general" data-snippet="...">`). Without `.oe_structure` and `<section data-snippet="...">`, Odoo disables all `+ Blocks` (orange `!` warnings) and breaks visual drag-and-drop editing.

## Architecture Fix
Separate `body_arch` (Odoo visual editor source) from `body_html` (Gmail-safe rendered email):
1. **`data/templates_arch/*.html` (7 files for `body_arch`)**: Keep native Odoo Mass Mailing editor markup (`o_layout`, `<style id="design-element">`, `o_mail_wrapper`, `o_mail_wrapper_td oe_structure`, `<section class="o_mail_snippet_general" data-snippet="...">`) with bundled `/vhealth_email_marketing/static/src/img/email/...` URLs, clean QWeb (SharpSpring tags fixed), inline image/button/footer/card styles, and zero `background: red`.
2. **`data/templates/*.html` + Dynamic Converter in `models/mailing.py`**: Keep `data/templates/*.html` as `body_html` baseline AND enhance `fix_odoo_email_html_for_gmail()` in `models/mailing.py` to convert any `.o_layout` + `<section>` HTML (including future user edits saved from Odoo's visual editor!) into a centered `600px` Gmail-safe `<table>` layout at render/send time (`_render_field`, `_create_and_send_launch_mailing`).
3. **Upgrade Hook (`_upgrade_fix_vhealth_templates` & `action_fix_gmail_layout`)**: Restore editable `body_arch` on any template whose `body_arch` lacks `oe_structure` (previously overwritten by `.20`–`.22`) without clobbering future edits once `oe_structure` is present.

## Tasks
1. Create `custom_addons/vhealth_email_marketing/data/templates_arch/` with all 7 Odoo-editable `body_arch` templates.
2. Update `models/mailing.py` (`load_bundled_arch_template`, `_convert_o_layout_to_gmail_table` inside `fix_odoo_email_html_for_gmail`, `action_fix_gmail_layout`, `_upgrade_fix_vhealth_templates`).
3. Update `__manifest__.py` to `20.0.1.0.23` and add unit tests in `tests/test_smoke.py` verifying both Odoo `oe_structure` editability in `body_arch` and Gmail `<table>` conversion for `body_html`.
4. Verify AST, XML, manifest, all 7 `templates_arch` + `templates` files, and dynamic conversion of edited `body_arch` -> Gmail `<table>`.
